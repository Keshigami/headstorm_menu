# The film

`demo/film.mp4` is 90 seconds in four chapters, made for engineers and project managers who have ninety seconds.

1. **What it does** (0 to 17 s): a terminal prompt runs the project's real first command and the response becomes a printed object. This menu was an image a moment ago. Then the stake: First run: 87% of items found. Can two layout rules close the gap?
2. **How it is built** (17 to 40 s): a paper model of the pipeline, stage by stage, with the reveal: Three runs against the same 71 items, the one line of code that matters, the API call and the tests.
3. **The proof** (40 to 68 s): the real app, recorded. First sample, one click: category, item, price Every box OCR found, then the JSON Batch over five menus: 100% against ground truth
4. **The answer** (68 to 90 s): 100%, items and prices · 71 items · 5 synthetic menus. The fake batch loop is gone. And it ships. One limit: Synthetic menus only. Photos will score lower. Then the prompt types `just setup && just up`.

`demo/film-60s.mp4` is the same without the proof chapter. `demo/demo.mp4` is the plain captioned walkthrough of the app.

Every number in the film comes from the project's own metrics, findings or a live response; nothing is drawn by hand. The film pipeline lives in the author's workspace, not in this repo.
